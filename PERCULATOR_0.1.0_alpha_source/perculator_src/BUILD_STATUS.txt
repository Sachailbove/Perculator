PERCULATOR 0.1.0-alpha

Contenuto:
- VST3 x64
- Standalone x64
- Cabinet IR loader WAV, senza IR predefiniti
- Finiture GUI: Dictatorship, Surf Party, Fetish Red
- Installer Inno Setup
- Workflow GitHub Actions per build Windows

Nota: l'installer .exe deve essere prodotto su Windows x64 con Visual Studio 2022, CMake e Inno Setup.
Questo pacchetto contiene il progetto compilabile e l'automazione della build.
